JSON czy TXT?

JSON zawiera jedną instrukcję. TXT może mieć wiele instrukcji wybieranych w linku parametrem punkt.

Każdy zapis w GitHubie tworzy osobny commit. Ręczne pobieranie i import pozostają dostępne.

Builder zapisze poprawny JSON z polem prompt. Maksymalnie 10 000 znaków.
